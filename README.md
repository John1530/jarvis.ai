# 🧠 JARVIS.AI

A futuristic **voice-controlled AI assistant** built using JavaScript, Web Speech API, and OpenAI integration.  
Inspired by Iron Man’s JARVIS, this project brings AI interaction directly into the browser.

---

## 🚀 Features

- 🎤 Voice command recognition (speech-to-text)
- 🧠 AI-powered responses using OpenAI API
- 🌐 Web automation (Google, YouTube, Gmail, etc.)
- ⏰ Real-time clock display
- 🌦️ Live weather updates using API
- 💬 Natural conversation mode
- 🔊 Text-to-speech response system
- ⚡ Multi-command support ("open youtube and search AI")

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Neon/Futuristic UI)
- JavaScript (Vanilla JS)
- Web Speech API
- OpenWeather API
- OpenAI API (GPT)
